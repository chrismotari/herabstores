# Herab Stores

Online grocery storefront, being migrated from a Laravel/Blade monolith to a REST API + Next.js + React Native.

- `api/`: Laravel API and Filament admin
- `apps/web`: Next.js storefront (planned)
- `apps/mobile`: Expo app (planned)

See [`spec.md`](spec.md) for the plan and progress, and [`CLAUDE.md`](CLAUDE.md) for dev commands and conventions.
